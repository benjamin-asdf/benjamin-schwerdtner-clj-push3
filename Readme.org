- Another Clojure implementation of the [[https://faculty.hampshire.edu/lspector/push3-description.html][push3]] programming language.
- Propeller problem parity: every Propeller/PSB benchmark problem expressed and runnable on this Push3.
- Chaitin's metabiology on Push3.
- Explorations (analogical reasoning, hyperdimensional computing, ARC) live on other branches, see [[*Experimental work][Experimental work]].

Push is a simple, stack based language designed as the target domain for program synthesis tasks.


* Clojush

Clojush, an implementation of Push/PushGP in Clojure that has been used for many research projects since 2010. Clojush is full-featured but has accumulated technical debt and is nontrivial to understand or modify: http://github.com/lspector/Clojush

* clj-push3-play

- Heavily reuse Clojush source code.
- Be slightly more data oriented.

** Interpreter

Preliminary interface:

#+BEGIN_SRC clojure
(require '[benjamin-schwerdtner.clj-push3-play.interpreter :as push])

(defn execute [program]
  (push/execute
   (push/setup-state)
   program
   {:max-executions 250}))


(->
 (execute '(2 2 :exec_y (:integer_dup :integer_*)))
 :stacks :push/integer)

[2 10000000000]
#+END_SRC

** Propeller problems

[[file:docs/propeller-recook.md][docs/propeller-recook.md]] describes the port. The instruction table grew
from 253 to 525; all 362 Propeller instructions have an equivalent, pinned
by ~propeller-test/alphabet-test~. Programs read their inputs with
~:in1~ .. ~:in8~ and PSB problems that answer by printing use the PRINT stack.

~propeller_problems/~ is a vendored copy of Lee Spector's [[https://github.com/lspector/propeller][Propeller]] (EPL).
It is not on the classpath and nothing loads it at runtime. It stays because
it is the reference the port is checked against: every problem in
~problems/propeller/problems.clj~ names its source file there (~:source~), and
the instruction inventory in ~test/benjamin_schwerdtner/problems/propeller_test.clj~ was
transcribed from ~propeller_problems/push/instructions/~.

** Metabiology

[[file:docs/metabiology.md][docs/metabiology.md]]. Push3 programs as Chaitin's software organisms: algorithmic
mutation (the mutation is itself a program) and the three regimes (exhaustive
search / cumulative evolution / intelligent design) measured against each
other. Fitness is Chaitin's toy model, the busy beaver (name the biggest number
you can), and the same regimes also run on the PSB suite.
